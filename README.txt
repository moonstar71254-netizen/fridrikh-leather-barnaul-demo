КОЖЕВЕННАЯ МАСТЕРСКАЯ СЕМЬИ ФРИДРИХ — ПАМЯТКА ВЛАДЕЛЬЦУ

1. КАК МЕНЯТЬ ТЕКСТЫ, ЦЕНЫ, КОНТАКТЫ И ФОТО
- Откройте файл site-config.js (в исходниках: public/site-config.js, на хостинге: рядом с index.html) в Блокноте или любом редакторе.
- Измените нужные строки (цены, адрес, график, ссылки на WhatsApp/Telegram) и сохраните в кодировке UTF-8. Пересборка сайта не требуется.
- Для замены фотографий положите новые файлы в папку images/ и пропишите их имена в блоке images внутри site-config.js.

2. ЗАПУСК НА СВОЕМ ХОСТИНГЕ (REG.RU, TIMEWEB, BEGET)
- Загрузите все содержимое папки dist/ в корневую папку сайта на хостинге (обычно public_html/ или www/).
- Внутри уже настроены относительные пути (base: './'), сайт откроется сразу без серверных настроек и без Node.js.

3. ПРИВЯЗКА ДОМЕНА БЕЗ ОПЛАТЫ ХОСТИНГА (VERCEL / CLOUDFLARE PAGES)
- Подключите этот GitHub-репозиторий в бесплатном тарифе Vercel или Cloudflare Pages (команда сборки: npm run build, папка вывода: dist).
- В панели регистратора домена (Reg.ru, Timeweb и др.) добавьте DNS-записи:
  A      @    -> 76.76.21.21
  CNAME  www  -> cname.vercel-dns.com
- После обновления DNS (обычно 15–60 минут) SSL-сертификат HTTPS выпустится автоматически.
